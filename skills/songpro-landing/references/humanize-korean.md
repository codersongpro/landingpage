
# Humanize Korean (채팅용 단일 콜 버전)

출처: epoko77-ai/im-not-ai v2.3.2 (MIT License, Copyright (c) 2026 epoko77-ai). 원본의 quick-rules.md(monolith fast path 룰북)를 채팅 환경에 맞게 옮겼다. 원본의 Python 게이트 스크립트·다중 에이전트 파이프라인은 Claude Code 플러그인에서만 돈다. 여기서는 변경률·게이트 판정을 스스로 추정한다.

## 작업 순서

1. 장르(칼럼·보고서·에세이·공문·안내문·대화체)와 격식 등급을 먼저 판단한다.
2. 문장별 내용 앵커(주장을 이루는 핵심 명사·개념어)를 속으로 목록화한다.
3. 아래 A~J 패턴을 탐지하고, 탐지된 구간만 고친다. 탐지되지 않은 문장은 그대로 둔다.
4. 자체검증 체크리스트로 점검하고 위반한 수정은 되돌린다.
5. 결과를 출력한다. 출력 형식: 윤문본 전체를 한 덩어리로 먼저 주고, 그 아래에 주요 수정 3~6건(패턴 ID, 원문→수정)과 자가 등급(A~D)을 짧게 붙인다. 사용자가 결과만 원하면 윤문본만 준다.

강도 조절: '가볍게'면 S1만 고친다. '정밀하게·제대로'면 S2까지 모두 보고 결과를 한 번 더 점검한다.

## 공통 원칙

**Do-NOT (탐지·윤문 모두 제외):** 고유명사·제품명·모델명·기관명, 수치·날짜·단위, 발화자가 있는 직접 인용(말했다·밝혔다·따르면 등 발화 표지가 붙은 큰따옴표), 법률 조문, 수학·화학·통계 표기, 영어 약어(LLM·GPU·MCP·API 등 업계 표준). 단 필자가 자문·강조를 따옴표로 감싼 수사 장치(발화 표지 없음)는 윤문 대상이다.

**서법 보존:** 당위·요구("~해야 한다")를 사실 단정("~한다")으로, 추측·유보("~일 수 있다")를 단정으로 바꾸지 않는다. 주장의 강도와 성격은 그대로 둔다. 표지가 반복돼 리듬을 지배하면 서법은 유지하고 배치만 바꾼다(I-4).

**내용 앵커:** 조사·어미는 바꿀 수 있지만 핵심 내용 명사의 원형 어휘는 결과에 최소 한 번 그대로 남긴다. AI 관용구·추상 표현을 덜어낼 때 수식어·형식명사만 제거하고, 앵커를 삭제하거나 동의어로 치환하지 않는다. 확신이 없으면 그 문장을 롤백한다.

**과윤문 가드:** 변경률 30% 초과면 경고, 50% 초과면 해당 부분 롤백. 내용 추가·삭제 금지.

## A. 번역투 — S1~S2

- **A-1** [S1] "~에 대해(서)" 한 문단 3회+ 밀집(고립 사용은 보존) → 목적격 조사로 직결("X에 대해 논의" → "X를 논의")
- **A-3** [S1] "~에 있어(서)" → "~에서" 또는 "~을 볼 때"
- **A-5** [S2] "~와 관련하여/관련된" → "~에", "~의"
- **A-6** [S2] "~에 기반하여/바탕으로" 남발 → "~로", "~을 보고"
- **A-7** [S1] "가지고 있다", have/make/take/give+명사 직역 → 형용사·동사 환원 또는 이중주어("강한 경쟁력을 가지고 있다" → "경쟁력이 강하다")
- **A-8** [S1] 이중 피동 "~되어진다/~지게 된다" → 능동 또는 단일 피동("판단되어진다" → "판단된다")
- **A-9** [S2] "~에 의해" 피동 → 행위자를 주어로("AI에 의해 생성" → "AI가 만든")
- **A-10** [S2] 같은 "~할 수 있다" 4회+ 반복 → 단정 전환 금지. 일부만 "~할 여지가 있다·~할 수도 있다"로 분산해 리듬만 깬다. 의학·법률·정책 텍스트는 원문 보존
- **A-11** [S2] "~을 위해" 목적절이 한 문단에 밀집할 때만 → "~려고", "~도록", "~위한"으로
- **A-15** [S2] 추상 주어 + 만능 동사(보여준다/제공한다/가져온다), 사역·인지 동사 직역 → 구체 주어로, 사역은 "X 때문에/덕분에" 부사절로, 인지 동사(suggest/show/indicate)는 "~에 따르면 ~이다"로
- **A-18** [S2] 명사 앞 3어절 이상 관형구 좌향 수식 → 문장 분리 또는 후치 동격절
- **A-19** [S2] 이중 조사 "~에서의/~에로의/~으로의/~에의/~으로부터의" → 절로 풀어쓰기(단순 "~의"는 비대상)
- **A-20** [S2] "~되고 있다/~지고 있다" 한 문단 3회+ → 일부만 추세 단언("심해졌다")으로
- **A-21** [S2] "단순한 X를 넘어 Y" → "X만이 아니라 Y다"로 풀거나 넘어-구 삭제
- **A-22** [S2] "~은/는 명확하다·분명하다" → 평가 술어를 걷고 명제를 단언으로. 확신 강도는 부사로 보존. 앞에서 논증한 결론이면 유지
- **A-24** [S2] "더 이상 ~ 않다/아니다" 문서 2회+ 또는 결말부 재정의 → "이제"로 환원하거나 변화 동사로. 윤문 중 "더 이상 A가 아니라 B"를 새로 만들지 않는다

## B. 영어 인용·용어 과다 — S2

- **B-1** 한글+괄호 영어 병기 매번 반복 → 첫 등장만 병기
- **B-2** 광고성 buzzword(seamless·robust·leverage 등) → 광고성만 한국어로 풀고 표준 technical term(API·prompt·token 등)은 원어 보존

## C. 구조적 AI 패턴 — S1~S2

- **C-2** [S2] 칼럼·리포트에서 3개 이상 연속 불릿 블록 → 문단 산문으로 통합, 나열이 의미 있는 지점만 유지
- **C-5** [S1] 이모지 남발(리스트 머리, 헤딩, 강조) → 칼럼·리포트면 전부 삭제
- **C-7** [S2] 문단 문두 "먼저-반면-결국" 3단 공식 → 접속사 1~2개로 줄이거나 본문에 녹임
- **C-8** [S1] "A인가, B인가"·"A가 아니라 B"·"~것이 아니라"·"~것은 아니다" 대구 2회+ → 한 번만 살리고 나머지는 비대칭 평서문으로. 전멸 금지. 연쇄로 몰려 있지 않으면 보존 우선
- **C-9** [S2] "1) 2) 3)" 나열 → 본문에 녹이거나 "우선~", "다음으로~"로 변주
- **C-10** [S2] 콜론 부제 헤딩 "X: Y" 반복 → 단일 명사구로 압축(학술 보고서의 실제 절 제목은 보존)
- **C-11** [S1] 연결어미(-고/-며/-지만/-면서/-아서/-어서) 직후 쉼표 → 쉼표 제거. 6회+는 강한 신호. 윤문 후 쉼표 개수가 원문보다 늘면 실패

## D. AI 특유의 관용구 — S1~S2

- **D-1** [S1] "결론적으로/따라서/이를 통해/그러므로/요약하면/정리하자면" 3회 초과 → 1~2건만 남김
- **D-2** [S1] "시사하는 바가 크다/주목할 만하다/매우 중요하다" → 삭제 또는 구체 결론으로
- **D-3** [S1] "크게 세 가지로 나눌 수 있다/다음과 같은" → 도입구 삭제하고 바로 본론
- **D-5** [S2] 의인화 추상 주어("기술이 묻는다", "시대가 부른다") → 사람·기관 주어로
- **D-6** [S2] "~할 때입니다/~시점입니다" → 구체 동사 단언, 문서당 1회 이하
- **D-7** [S2] "X에서 Y로/X을 넘어 Y로" 반복 → 직접 단언, 문서당 1회 이하
- **D-8** [S2] "필요한/중요한 것은 ~이다", "문제는/핵심은/관건은 ~다" → 주어-서술 직결("필요한 것은 방향이다" → "방향이 필요하다")
- **D-9** [S2] "(으)로 이어진다"·"~에 직결된다" + 결산용 "결국" 2회+ → 인과를 구체로. "결국"은 1회만. 새로 만들지 않는다
- **D-10** [S2] 문장 말미 "~하는 이유다" 도치 → "그래서 ~다"로, 문서당 1회 이하. 새로 만들지 않는다
- **D-11** [S2] 결말부 문두 "향후/앞으로/중장기적으로" → 삭제 또는 원문의 실제 시점으로(날조 금지)
- **D-12** [S2] "과제도 남아 있다/한계도 분명하다" 문패 문장 → 삭제하고 실제 과제를 첫 문장으로
- **D-13** [S2] 에세이 결말의 "어쩌면 ~일 것이다/비로소" → 성찰 부사를 빼고 구체 서술로
- **D-14** [S2] 감각 술어 평가문("진단은 서늘하다") 1회+, 사전 은유(잠식·청사진·적신호·경고등·신호탄·움켜쥐다·뿌리내리다·짓누르다) 1회+, 기타 개념 은유 3회+, 같은 은유 어근 3회+ → 명제로 직역화("잠식한다" → "점유율을 뺏는다"). 관통 은유는 1회만 남김. 명제가 불명하면 보존

## E. 리듬·문장 길이 균일성 — S2

- **E-1** 문장 길이 균일 + 장문 부재 → 문단마다 단문 1~2개와 인접 문장을 이은 장문 1개(내용 추가 금지)
- **E-2** 동일 종결어미 4문장+ 연속, 진행형 "~고 있다" 남용 → 종결어미 다양화, 가능하면 단순 시제로("읽고 있다" → "읽는다")
- **E-7** 대화체에서 경어법 등급 혼재 → 한 등급으로 통일

## F. 과도한 수식·중복 — S2

- **F-4** -성/-적/-화 명사화, -tion/-ment 직역 누적(문서 12회+) → 동사·형용사 어근으로("the implementation of the policy" → "정책 시행")
- **F-5** "~적 N" 추상 체인 3회+ → "전략 함의", "실천의 기반"처럼 풀어쓰기
- **F-7** 범용 정책동사(확대·강화·개선·확보·마련·구축) 밀집 → 구체 행위 동사로

## G. 과도한 완곡 — S2

- **G-1** 같은 추측 종결("~로 보인다/~로 판단된다") 반복 → 단정 전환 금지, 종결 형태만 변주. 부정이 낀 문장은 극성 확인 후 손대고 애매하면 보존
- **G-2** 이중·삼중 완곡("~할 가능성이 있을 수 있다") → 완곡 하나만 남김. 의학·법률·정책·계약 문서는 원문 보존

## H. 접속사 남발 — S2

- **H-4** "즉" 남발 → "곧", "말하자면"으로 변주 또는 생략, 문서당 2회 이하

## I. 형식명사·의존명사 과다 — S2

- **I-2** "주목할 점은/~라는 점에 있다" → "X는 ~다" 직설로
- **I-3** "~다는 것이다/~다는 뜻이다" → "~다"로, 합산 2회 이하
- **I-4** 당위로 끝나는 문단 2개+ → 당위 문장을 문단 앞·중간으로 옮겨 결말 자리를 비움. 삭제·서법 치환 금지
- **I-7** 출처 없는 "~다는 분석이다/평가다" → 출처 있으면 보존, 없으면 직접 서술(출처 날조 금지)

## J. 시각 장식 남용 — S2~S3

- **J-1** 문장마다 ** 볼드 → 칼럼·리포트면 본문 볼드 거의 제거
- **J-2** 따옴표 강조 5회+ → 진짜 인용만 남김
- **J-3** 대시(—) 부가 설명이 문장마다 반복 → 쉼표, 괄호, 별도 문장으로. 원문에 이미 있던 대시는 보존

## 자체검증 체크리스트

하나라도 위반하면 해당 수정을 되돌린다. 재점검은 1회까지.

1. 고유명사·수치·날짜·인용·내용 앵커 100% 보존. 표준 technical term은 원어 보존(prompt → "지시문" 금지)
2. 변경률 30% 이하(자가 추정)
3. 장르 이탈 없음: 칼럼이 에세이로, 리포트가 블로그체로 변하지 않았는가
4. 격식 보존(양방향): 격식체는 격식체로, 구어체는 구어체로. '-했-'을 '-하였-'로 올리지도 않는다
5. 잔존 S1 0건: D-1~D-3, A-7, A-8, C-5, C-10, C-11, J-2. C-11은 쉼표가 늘어도 실패. D-14 발동분도 잔존 0
6. 빼기 전용: 원문에 없던 비유·수사·상투구를 새로 심지 않았는가. 살아 있는 구어(짧은 감탄·반문)는 보존

## 등급 기준

- **A**: S1 잔존 0, S2 잔존 2 이하, 변경률 10~25%, 체크리스트 6항 통과
- **B**: S1 잔존 0, S2 잔존 4 이하, 5항 이상 통과
- **C**: S1 잔존 1~2 또는 4항 이하 통과 → '정밀하게' 재실행 권고
- **D**: S1 잔존 3+ 또는 변경률 50% 초과 → 중단 권고
